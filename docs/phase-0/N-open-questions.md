## 2. Риски

| Риск | Вероятность / влияние | Что делаем |
|---|---|---|
| AI-оценка не проходит пороги качества | Средняя / высокое | Бенчмарк до продукта; запасной вариант — «только разбор» (ТЗ §9.4) |
| Баллы расходятся с реальными экзаменаторами | Высокая / среднее | Только ориентировочные диапазоны; сбор официальных результатов; экзаменаторы — по решению |
| Права на текст дескрипторов и образцы | Средняя / среднее | Своё руководство; запрос разрешения |
| Обобщение биллинга WG ломает оплату WG | Низкая / высокое | Маленькие шаги, тесты WG, Sandbox, отдельные деплои |
| Эссе как личные данные (утечка, журналы, бэкапы) | Низкая / высокое | Шифрование полей, без текста в журналах, удаление, срок бэкапов, раздел в политике |
| Рост стоимости AI или смена моделей провайдером | Средняя / среднее | Квоты, пределы, маршрутизация моделей, отдельные ключи |
| Инструкции внутри эссе (prompt injection) | Средняя / низкое | Эссе как данные, тест на набор G |
| Зависимость Фазы 4 от онлайн-проверки в Edu и заявки EX | Средняя / среднее | MVP без практики; Фаза 4 планируется по факту готовности |
| Конкуренция бесплатных «IELTS checker» с точным баллом | Высокая / среднее | Отличие — честность, разбор с цитатами и связь с практикой GoNative |
| Нагрузка на общую очередь и БД MultiAdmin | Низкая / среднее | Своя очередь `exam`, лимит параллельности |
