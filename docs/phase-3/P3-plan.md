## 3. Задачи

Везде одинаково:
- тексты интерфейса — en и ru в `web/messages/*.json`, тест на совпадение ключей;
- эссе не попадает в журналы, URL, аналитику и сообщения об ошибках;
- числа баллов — только через `presentEstimate` (диапазон приходит из API уже готовым, веб его не пересчитывает,
  только показывает с подписью);
- light/dark/system, ширина от 320 до 1440 px;
- платных вызовов нет, кроме P3.7 и P3.8 по отдельному «да».

**✅ Готово 2026-11-24.**

- Вход, регистрация, «присоединиться с GoNative», Google, активация, повторное письмо, сброс пароля — en/ru.

### P3.3. Задание и редактор (M)

**✅ Готово 2026-11-24.**
- **Главная Writing:** «Новое эссе», остаток бесплатных разборов и дата обновления, последние эссе со статусом.
- **Выбор задания:**
  - Academic или General Training (по умолчанию — из профиля);
  - библиотека с фильтром по типу и пометкой «не официальное»;
  - своё задание с проверкой в браузере по правилам бэкенда (20–600 символов, ≥ 4 слов, английский).
- **Редактор:**
  - задание и условия экзамена; счётчик «≈ N слов» по общему правилу `whitespace-v1` из `@gonative/exam-domain`;
  - подсказка до 250 слов, проверка орфографии браузера выключена — как на экзамене;
  - необязательный таймер на 40 минут переживает перезагрузку и ничего не блокирует;
  - удаление черновика с подтверждением.
- **Автосохранение** (`web/src/lib/draft-sync.ts`):
  - копия в браузере при каждом изменении; сервер — после паузы 1,5 с (не реже раза в 10 с) с ожидаемой ревизией;
  - без связи текст остаётся, сохранение повторяется и продолжается по событию `online`; при уходе со страницы
    с несохранённым текстом браузер предупреждает;
  - после перезагрузки несохранённая копия из браузера восстанавливается и досохраняется;
  - если эссе изменили в другой вкладке, человек выбирает версию — молча ничего не перезаписывается;
  - копия в браузере стирается при удалении черновика, удалении данных и выходе.
- **Отправленное эссе** пока показывается только для чтения: экран разбора — P3.4.
- **Тесты веба:** 8, новый `writing` покрывает весь путь, включая обрыв связи, восстановление и конфликт.
  Мутация (нет восстановления из браузера) ловится.

### P3.4. Оценка и страница результата (L)

**✅ Готово 2026-11-24.**
- **Отправка** из редактора: диалог показывает число слов, остаток бесплатных разборов, язык объяснений, что текст
  заморозится и что эссе уйдёт Anthropic.
  - Черновик сначала досохраняется; если не удалось — отправки нет.
  - Ключ идемпотентности фиксирован, пока диалог открыт; повтор после сбоя идёт с новым ключом.
  - Отказы (квота, лимиты, оценка выключена, параллельная оценка) объясняются словами; без квоты кнопка неактивна.
- **Ожидание:** статус, секундомер, опрос раз в 2,5 с, можно уйти и вернуться; через 5 минут — «дольше обычного».
  Сбой — «не засчитано, попробуйте снова».
- **Разбор:**
  - 4 критерия: диапазон «≈ 5.5–6.5» с подписью «ориентировочно» у каждого числа и общая пометка «не официальный
    результат» (ADR-003); сводка, низкая уверенность, «не оценено» для неполного разбора;
  - 3–5 главных исправлений;
  - эссе с подсветкой по `span` в нормализованном тексте (`highlightSegments` в `exam-domain`, тесты): ошибки,
    «можно лучше», сильные стороны; пересечения допускаются;
  - находка, чья цитата не совпала с текстом, показывается без подсветки с пометкой;
  - связь текст ↔ замечание в обе стороны (мышь и клавиатура), фильтры по критериям и сильным сторонам;
  - названия навыков en/ru.
- **Жалобы:** на замечание или на весь разбор, необязательное разрешение показать эссе администратору.
- **«Написать новую версию»:** новый черновик из этого эссе (`from_attempt`).
- **Тесты:** пакет — 54 (подсветка: пересечения, кодовые точки, неверные цитаты); веб — 9, новый `result` покрывает
  весь путь. Мутация (подсветка без сверки цитаты) ловится.
- **Не проверено:** настоящая оценка через веб — в P3.7 (платно, по «да»).

|---|---|
| Отправка с подтверждением: показ остатка квоты; ключ идемпотентности | редактор |
| Отказы в понятных словах:<br>• квота исчерпана;<br>• лимит в минуту;<br>• оценка временно выключена;<br>• повтор того же текста — открывает прежний результат без траты квоты | `lib/errors.ts` |
| Экран ожидания: статус, таймер, опрос; можно уйти и вернуться | `[uuid]` (состояние `assessing`) |

    последний диапазон подписан «ориентировочно»; есть таблица для доступности;
  - частые проблемы по навыкам: на 100 слов, «стоит поработать» / «обратите внимание», тренд, «мало эссе для
    вывода»; навыки без проблем не показываются;
  - пустое состояние до первого разбора.
- **Мои результаты** `/ielts/results`:
  - официальный балл Writing (шкала каталога 0–9 с шагом 0.5) и дата в пределах бэкенда;
  - отдельное согласие на калибровку, выключенное по умолчанию; его можно дать и отозвать позже;
  - сравнение с нашими оценками за окно до экзамена с оговоркой про Task 1 и день экзамена;
  - удаление.
- **Тесты веба:** 10, новый `progress`. Мутация (согласие включено по умолчанию) ловится.
