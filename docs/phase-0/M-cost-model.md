## 3. Платежи

Paddle — продавец (Merchant of Record): налоги и возвраты на его стороне. Стандартная комиссия Paddle — около 5 % + $0.50
за транзакцию (проверить по договору). На дешёвых разовых покупках фиксированная часть заметна: пакет за €5 теряет
≈ 15 %, за €15 — ≈ 8 %.

## 5. Контроль расходов (обязательно до запуска оплаты)

1. **Предел на одну оценку** (`budget_usd` прогона, гипотеза $0.25) → `partial`, без повторных платных вызовов.
2. **Квоты** по плану и месяцу + **денежный предел AI на пользователя в месяц** (как у WG: Free $1 / Pro $6 — подобрать для Exams).
3. **Повтор того же текста** — сохранённый результат, а не новая оценка.
4. **Частота:** именованные лимитеры (на пользователя, IP, параллельные оценки — 1).
5. **Максимальная длина** текста и задания.
6. **Отдельные ключи API Exams** с лимитом расходов у провайдера (C2 §4.2).
7. **Мониторинг:** стоимость на оценку и на платящего пользователя в админке; оповещение при росте средней стоимости.
8. **Запасной маршрут** моделей — только не дороже основного (или с отдельным пределом).
