Здесь только правила работы. Статус, решения и журнал ведутся в [PLAN.md](PLAN.md):

## Что это

функция — IELTS Writing Checker. ТЗ: [docs/SPEC.md](docs/SPEC.md) (источник
требований, не редактировать). Мастер-план: [PLAN.md](PLAN.md).

## Жёсткие правила

1. **Фаза 0 — только чтение** для всех существующих приложений и баз. Не меняйте
   MultiAdmin, WG, GoNative и их БД, пока владелец не утвердит архитектуру (gate Фазы 0).
2. **Платные AI-вызовы** — только после явного «да» владельца с конкретным лимитом в долларах
   на конкретный прогон. Фактическую стоимость записывайте в PLAN.md.
3. **Баллы.** Число попадает в интерфейс только через `presentEstimate` из `@gonative/exam-domain`:
   до калибровки — широкий ориентировочный диапазон с подписью «ориентировочно». Никогда не называйте
   оценку официальной ([ADR-003](docs/decisions/ADR-003-score-claims.md)).
4. **Эссе пользователей — личные данные:** не логировать текст, не класть в бенчмарки и примеры,
   не отправлять в обучение моделей.
5. **Git — источник истины.** Коммит, push, deploy, изменения на сервере и в production-конфигурации —
   только по явной просьбе владельца в текущей задаче. Секреты не коммитить.
6. **Материалы экзаменов.** Не копировать официальные задания и ответы в репозиторий без
   подтверждённой лицензии (см. [benchmarks/README.md](benchmarks/README.md)).
7. **Миграции и БД MultiAdmin — чрезвычайная осторожность.** 2026-08-18 одна команда агента снесла почти
   все таблицы production-БД, спас только снимок VPS. Поэтому:
   - **Запрещено всегда, на любой БД:**
     - `migrate:fresh`, `migrate:refresh`, `migrate:reset`, `migrate:rollback`, `db:wipe`;
     - `migrate` без `--path`;
     - `DROP`, `TRUNCATE`, массовый `DELETE`/`UPDATE` без условия;
     - любая запись через `mysql_production` или `DB_REMOTE_*`.

     Если кажется, что без такой команды не обойтись, — остановиться и спросить владельца.
   - **Перед любой командой artisan, которая трогает БД:**
     - убедиться, что вы в настоящей копии MultiAdmin (`/Users/avkudrya/Documents/Projects/My/MultiVerse/MultiAdmin`),
       а не в клоне;
     - проверить цель в `.env`: `DB_HOST=127.0.0.1`, `DB_PORT=3306`, `DB_DATABASE=multi`,
       `DB_USERNAME=multiadmin_local` (локальная sandbox);
     - читать только эти ключи через `grep`, пароли и `DB_REMOTE_*` не выводить.
   - **В локальном `.env` стоит `APP_ENV=production`.** Флаг `--force` снимает единственное подтверждение,
     поэтому ставить его только после проверки цели.
   - **Своя миграция:**
     - только добавочная: новые таблицы `ex_*`; `down()` удаляет только их; существующие таблицы и строки
       не меняет;
     - применяется только по точному пути: сначала
       `migrate --path=database/migrations/<файл>.php --pretend --force`, в SQL проверить, что там только
       `create table`/`alter table` своих таблиц, и только потом тот же вызов без `--pretend`.
   - **В production миграции попадают только через Git и штатный деплой,** после явного «да» владельца
     в текущей задаче и с бэкапом затрагиваемых таблиц. Руками на сервере — никогда.
   - **Тесты — только на SQLite в памяти,** по одному набору за вызов. Полный `phpunit` не запускать:
     `tests/Feature/Auth/*` и `tests/Feature/ProfileTest` делают `RefreshDatabase` (= `migrate:fresh`)
     на локальной MySQL. Новые тесты обязаны сами переключать соединение на SQLite.

## Команды

Node 24 (`.nvmrc`); скрипты сами выбирают его через `scripts/with-node24.sh`.

```bash
npm install
npm run typecheck      # пакеты
npm test               # тесты packages/exam-domain
npm run typecheck:web
npm run lint
npm run build
npm run check          # всё вышеперечисленное
npm run dev            # http://127.0.0.1:3302
```

## Конвенции

- Документы, план и ADR — на русском; код, комментарии и идентификаторы — на английском.
- Офсеты в тексте эссе — кодовые точки Unicode нормализованного текста (`packages/exam-domain/src/text.ts`),
  одинаково в PHP и TS.
- Конфигурация экзаменов не содержит допущений IELTS: шкалы, агрегации и критерии — данные
  (`packages/exam-domain/src/exam-config.ts`). Новый экзамен — новая конфигурация, не новый код.
- Факты об экзаменах в конфигурации имеют статус `draft`, пока не сверены с официальными источниками.
  Проверенные конфигурации — `packages/exam-domain/catalog/*.json`; меняются только вместе с документом
  проверки (`docs/phase-0/D1-*`) и тестом `catalog.test.ts`.
- Дословный текст официальных дескрипторов и образцов IELTS не вставлять в промпты, интерфейс и репозиторий
  без разрешения IELTS Partners (D1, «Правовой момент»). Руководство по оценке пишем своими словами.
