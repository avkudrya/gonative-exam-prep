# E1. Эталонные данные для бенчмарка: источники и лицензии (P0.4)

**Статус:** проверено 2026-11-23. Часть документа E (план бенчмарка). Только чтение страниц источников:
данные не скачивались и в репозиторий не добавлялись.

## Итог

**В открытом доступе нет набора эссе IELTS с оценками экзаменаторов, который можно законно использовать
в коммерческом продукте.**
- Официальных образцов всего шесть, и коммерческое использование требует письменного разрешения.
- Крупные корпуса Cambridge разрешены только для некоммерческих исследований.
- Наборы IELTS на Hugging Face — неизвестного происхождения, и оценки в них, по всей видимости, не человеческие.

Следствие для ADR-003: на публичных данных Фаза 1 может измерить качество разбора и согласие с
людьми-оценщиками, но **не может откалибровать баллы относительно экзаменаторов IELTS**. Без отдельного
шага (см. «Путь к калибровке») ориентировочный показ остаётся ориентировочным.

## Наборы для Фазы 1 (предложение)

| Набор | Что измеряет | Чьи данные |
|---|---|---|
| **S. Вставленные ошибки** | Полнота и точность находок, ложные исправления, точность цитат — эталон известен точно | Наши: исходные эссе пишет модель, человек вычитывает, ошибки вставляет код |
| **G. Граничные случаи** | ≤ 20 слов, короче минимума, не по теме, другой язык, списки вместо текста, копия задания, инструкции модели внутри эссе | Наши |
| **R. Стабильность** | Разброс диапазонов и находок при повторах | Любые из наших |
| **H1. ELLIPSE** (test-часть) | Ранговая корреляция наших CC / LR / GRA с человеческими аналитическими оценками | CC BY 4.0, с указанием авторства |
| **H2. EWCCE** (если файлы доступны) | Расхождение наших полос по критериям с оценками двух преподавателей; согласие самих преподавателей между собой — потолок ожидаемой точности | CC BY 4.0, после расшифровки |

dev и test разделяются до первого прогона; промпты на test не настраиваются.

## Путь к калибровке (ADR-003, `calibrated`)

1. **Экзаменаторы.** 1–2 сертифицированных экзаменатора IELTS дважды оценивают 100–200 эссе
   (тексты — наши или из H1/H2 с лицензией CC BY). Единственный путь к настоящей калибровке до запуска.
   Стоит денег; смету соберу, если решим.
2. **Реальные результаты пользователей.** После экзамена пользователь по желанию вводит официальную оценку
   за Writing, и мы сравниваем её с нашими оценками его последних попыток. Бесплатно и масштабируется,
   но шумно: экзамен — другой день и другое задание. Нужно согласие в Privacy Policy. Функция для
   Фазы 6 и дальше.
3. **Коммерческая лицензия CUP&A** на FCE или Write & Improve — для проверки находок по настоящей разметке
   ошибок. Не IELTS, баллы не калибрует.
