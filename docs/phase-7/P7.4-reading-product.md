# P7.4. Reading в продукте

**Статус:** код готов 2026-11-27 (владелец: «начинай P7.4. Миграцию можешь запушить»). MultiAdmin `03e4a9d8` запушен с миграцией.
Затрат нет: AI в попытке не участвует. В production ничего не включено: нужен ваш деплой и флаг (§4).

## 1. Что получает ученик

- **Раздел «Reading» в меню.** Ссылка видна, только пока включён `EXAM_READING_ENABLED`.
- **Выбор:**
  - полный тест: 3 текста, 40 вопросов, 60 минут;
  - один текст: около 20 минут;
  - таймер мягкий (предупреждает и даёт закончить) или строгий (по истечении времени сдаёт сам, как на экзамене).
- **Экран теста как на компьютерном экзамене:**
  - текст слева, вопросы справа; на телефоне — вкладки «Текст» и «Вопросы»; у полного теста вкладки трёх текстов;
  - выделение фразы в тексте;
  - карта вопросов 1–40 с отметками «есть ответ» и «вернуться позже»;
  - пропуски заполняются прямо в предложении;
  - автосохранение на сервер и копия в браузере: ответы, набранные без связи, восстановятся при следующем открытии.
- **Разбор:**
  - сырой счёт из 40 — точный;
  - для полного теста — ориентировочная полоса через `EstimatePresenter` (ADR-003). Ниже нижнего официального порога числа
    нет. У одного текста полосы нет;
  - сводка по типам вопросов («True / False / Not Given 6 / 7»);
  - по каждому вопросу: ответ ученика, верный ответ, объяснение на языке разбора (en, ru или uk) и кнопка
    «Показать в тексте», которая подсвечивает цитату-доказательство;
  - ссылка на главу гайда Reading. Глава пока только на en, поэтому ссылка ведёт на en-версию.
- **Квота:**
  - бесплатно — 2 теста Reading в месяц: полный тест или один текст считается как один (P7.1 §11 вопрос 4);
  - в платном тарифе ограничения нет;
  - тест засчитывается в момент старта. Удаление данных счётчик месяца не обнуляет.

## 2. MultiAdmin (`03e4a9d8`)

- **Миграция `2026_11_27_130000_create_exam_reading_tables.php`** (только добавочная, SQL проверен через `--pretend`, локально
  применена):
  - `ex_reading_tests`: тест библиотеки, статус `review`, `published` или `retired`, хеш содержимого;
  - `ex_reading_sections`: текст и группы вопросов с ключами;
  - `ex_reading_attempts`: попытка, ответы, разметка, счёт;
  - столбец `reading_tests` в `ex_usage_periods`.

  Отдельной таблицы вопросов (P7.1 §8) нет: вопросы лежат в JSON секции, статистику по вопросам (P7.1 §4 шаг 7) можно
  посчитать из попыток. Таблицу добавим, если понадобится.
- **Библиотека:** `resources/data/exam/library-ielts-reading-academic.v1.json` закреплён SHA-256 в
  `config/exam.php` (`exam.data.reading_libraries`). Команда `exam:import-reading [--apply]`:
  - перед записью проверяет каждую секцию тем же `ReadingForm` и нумерацию 1–40;
  - содержимое теста под ключом и версией не меняется: новое содержимое — новая версия библиотеки;
  - статус может меняться.
- **`ReadingAttempts`:**
  - старт и квота;
  - автосохранение; в строгом режиме после срока и 120 секунд запаса ответы не принимаются;
  - сдача: подсчёт `ReadingAnswers` по ключу. Повторная сдача возвращает тот же результат;
  - выход;
  - у ученика одна открытая попытка.
- **`ReadingPresenter`:** до сдачи API не отдаёт ключи, доказательства и объяснения (проверено тестом), после сдачи — весь
  разбор.
- **API `api/exam/reading`:**
  - `GET reading`;
  - `POST reading/attempts`;
  - `GET reading/attempts/{uuid}`;
  - `PUT …/answers`;
  - `POST …/submit` и `POST …/abandon`.

  Новые поля:
  - `reading_tests` в `entitlements`;
  - `ex_reading_attempts` в удалении данных.
- **Флаги:**
  - `EXAM_READING_ENABLED` — Reading включён;
  - `EXAM_READING_DRAFTS` — показывать и тесты в статусе `review`, чтобы опробовать их до публикации.
- **Тесты:** `ReadingApiTest`, 5 случаев:
  - импорт и черновики;
  - ключи скрыты до сдачи, разбор и полоса;
  - один текст, квота и выход;
  - строгий срок;
  - чужая попытка недоступна, удаление данных.

  Exam 179/179.

## 3. Сайт и exam-prep

- **Библиотека:** `packages/exam-domain/library/ielts-reading-academic.v1.json` собирается из пилота командой
  `npm run bench:reading-library`; режим `--check` проверяет, что файл актуален. Статусы тестов задаются в сборщике; сейчас оба
  `review`. Тест пакета проверяет каждый тест библиотеки через `checkReadingTest` и наличие объяснений en/ru/uk. Пакет 96/96.
- **Страницы:** `/ielts/reading` и `/ielts/reading/[uuid]`. Компонент `reading.tsx`, маршруты BFF (точный allowlist), схемы,
  тексты en, ru и uk, пункт меню.
- **Сквозной тест `test/reading.test.mjs`** (Playwright, мок бэкенда на настоящих данных библиотеки):
  - меню;
  - один текст на мягком таймере;
  - ответы, заполнение пропуска, отметка «вернуться», автосохранение, выделение;
  - диалог сдачи;
  - разбор: счёт, нет полосы, типы, объяснение на ru, подсветка доказательства;
  - полный тест с восстановлением ответов из браузера, 40/40, «≈ 8–9»;
  - вкладки на телефоне.

  Тесты сайта 23/23.

## 4. Production — по шагам

1. **Бэкап `ex_usage_periods`.** Миграция добавляет в эту таблицу столбец со значением 0 по умолчанию, остальное — новые таблицы.
2. **Деплой MultiAdmin** — штатный, с миграцией `2026_11_27_130000_create_exam_reading_tables.php`. Пока флаг выключен, для
   учеников ничего не меняется.
3. **Импорт библиотеки на сервере:**
   ```
   php artisan exam:import-reading          # ожидается: 2 insert (academic-1, academic-2), status review
   php artisan exam:import-reading --apply  # Inserted 2 test(s)
   ```
4. **Флаги** в `shared/.env`, затем сброс кэша конфигурации, как в прошлые разы:
   - `EXAM_READING_ENABLED=true`;
   - `EXAM_READING_DRAFTS=true` — пока тесты на вашей вычитке. Иначе список тестов будет пуст.
5. **Деплой сайта** — сделаю по вашей команде «деплой».
6. **Живая проверка:**
   - меню → Reading → «Только этот текст · 20 мин» → ответить на часть вопросов → «Сдать ответы»;
   - в разборе: счёт, объяснения на языке разбора, «Показать в тексте»;
   - затем один полный тест.

   Учтите, что это 2 теста бесплатной квоты месяца.
7. **После вычитки** `review.md` (P7.3):
   - в сборщике библиотеки ставлю тестам статус `published`, вы ещё раз запускаете `exam:import-reading --apply`
     (сменятся только статусы);
   - убираете `EXAM_READING_DRAFTS`;
   - ошибки ключа, если найдутся, правим новой версией библиотеки `v2`.

**Откат:** выключить `EXAM_READING_ENABLED`. Пункт меню и страницы Reading исчезнут, старт и сдача ответят 503, попытки останутся в базе.
