Условие из [PLAN.md](../../PLAN.md): API — каталог, попытки, оценка, результаты, навыки, официальные результаты
пользователей, учёт стоимости; тесты зелёные.

| Пункт | Что есть (`api/exam/*`, за флагом `EXAM_API_ENABLED`) | Чем подтверждено |
|---|---|---|
| Каталог | `GET catalog` — проверенные версии IELTS Academic и General Training (копии с SHA); `GET tasks`, `tasks/{uuid}` — библиотека 30 своих заданий Task 2, помечены неофициальными | `ExamImportTest`, `ExamApiAttemptsTest` |
| Попытки | `attempts`: создание (задание из библиотеки или своё), автосохранение черновика с ревизией, список, удаление; текст зашифрован | `ExamApiAttemptsTest`, `ExamStorageTest` |
| Оценка | `POST attempts/{uuid}/submit` — идемпотентно, квота и лимиты при постановке, резерв денег, очередь `exam`, джоб с жёстким бюджетом. Повтор того же текста — без квоты. Код-правила (короткий текст, другой язык) — бесплатно | `AssessmentJobTest`, `ExamQuotaTest`; 33 платные оценки в локальной sandbox |
| Результаты | `GET attempts/{uuid}/assessment` — контракт `assessmentResult` v1; числа только через порт `presentEstimate` (148 общих случаев с TS), ориентировочный диапазон; в сводках нет полос (`exam-p1-3` + `ScoreMentions`) | `EstimatePresenterTest`, `ScoreMentionsTest`, `ResultIntegrity` |
| Навыки | `GET skills` — ошибки и слабости → сигналы навыков (на 100 слов, тренд, уверенность) и тренд критериев диапазонами | `ExamProgressTest` |
| Официальные результаты | `reported-results` — CRUD, проверка по шкалам каталога, отдельное отзываемое согласие на калибровку, сравнение с оценками | `ExamProgressTest` |
| Учёт стоимости | Каждый вызов — `ai_usage_events` (`feature = exam`, свои ключи Exams); стоимость оценки — `ex_assessments`; месяц пользователя — `ex_usage_periods`; бесплатно 2 оценки и $0.50 в месяц, не больше $0.25 на оценку; админка — расходы по дням и на оценку | `ExamQuotaTest`, `AssessmentJobTest`, `ExamAdminTest` |
| Тесты зелёные | см. §2 | — |

**Сверх условия:**
- **Общий слой продуктов:** аккаунты, токены, права, лимитеры, закрытие, админ. Worksheets теперь работает поверх
  него, его тесты без правок.
- **Жалобы на разбор:** `attempts/{uuid}/reports`.
- **Удаление данных Exams:** `DELETE data`.
- **Приватность эссе:** текст не попадает в журналы, ошибки провайдера сокращаются.
- **Админка `admin/exams`:** оценки, жалобы (эссе — только с разрешения пользователя), версии и импорт, ручной доступ,
  расходы.

## 3. Качество оценки на продуктовом пайплайне

Синтетические эссе бенчмарка, Sonnet, `p1/exam-p1-3`. Подробно — `benchmarks/runs/exam-p2-ru-injection` и `exam-p2-p13-check`.

- **Надёжность:** 33 оценки из 33 успешны. В среднем $0.059 и 27–28 с на оценку.
- **Вставленные ошибки:** находятся в 98 % случаев с объяснениями на русском и в 100 % — на английском.
- **Объяснения на русском:** во всех случаях; исправления — на английском, как и должны.
- **ru и en:** на одном эссе расходятся не больше чем на 1 полосу по критерию, без систематического сдвига.
- **Инъекции:** ни одна (на английском и на русском, в сильном и слабом эссе) не подняла полосы.
- **Сводки без полос:** после `exam-p1-3` — 0 сводок из 40 (было 17).

## 6. Ограничения, с которыми идём дальше

1. **Калибровки нет.** Пользователь видит только ориентировочный диапазон (ADR-003). Калибровка (H2 и согласия
   на официальные результаты) — до публичного запуска.
2. **Проверки находок вторым вендором в продукте нет.** Пайплайн P1 — один вызов на критерий. Это осознанно, по
   итогам Фазы 1 (стоимость и время); в документ K нужна пометка.
3. **Инъекции.** Модель коротко упоминает «вставку не учитывал» в нескольких сводках. На полосы это не влияет.
4. **Только Writing Task 2.** Task 1 — Фаза 5. Оплата (Paddle) — Фаза 6; до неё только бесплатный план и ручной доступ.
5. **Локальная sandbox:** тестовый аккаунт #2639 с 33 оценками, импортированные версии, руководство и 30 заданий.
   Production не трогали.

## 7. Перед деплоем в production

Каждый пункт — отдельное «да» владельца, когда придёт время (вместе с Фазой 3 или раньше):

1. **Push** `main` MultiAdmin в `origin`: 12 коммитов, включая коммиты сессии WG.
2. **Бэкап и миграция:** бэкап; миграция `2026_11_23_120000_create_exam_tables` только штатным деплоем
   по точному пути. Она только создаёт `ex_*`.
3. **Воркер:** очередь `exam` (`deployment/supervisor/laravel-exam.ini.example`), правка `deploy.sh` (рестарт
   воркера), задача `sweep-exam-assessments`.
4. **Ключи и флаги в `.env` production:** `EXAM_ANTHROPIC_API_KEY` (отдельный проект), `EXAMS_WEB_URL`;
   `EXAM_API_ENABLED` и `EXAM_ASSESSMENT_ENABLED` сначала выключены.
5. **Импорт:** `exam:import-catalog`, `exam:import-guide`, `exam:import-tasks` — сначала предпросмотр, потом `--apply`.
6. **Включение флагов** — когда готов веб Фазы 3.
