# J. Проверка мультиязычности и мультиэкзаменности

**Статус:** v1 (2026-11-23). **ТЗ:** §2.3, §5, §17, §24.4, §26 J.

## 1. Что доказано тестами

`packages/exam-domain` (`npm test`, 26 тестов):

| Требование | Чем доказано |
|---|---|
| Одна модель для разных экзаменов и языков | IELTS Academic, IELTS General Training (`catalog/*.json`, verified) и Goethe-Zertifikat B1 (`test/fixtures/goethe-b1.ts`, иллюстрация) проходят одну схему `exam` |
| Разные шкалы | IELTS — полосы 0–9 (критерий шаг 1, задание шаг 0.5); Goethe — баллы; есть `levels` (CEFR, A–E) и `descriptive` |
| Разные агрегации | IELTS — взвешенное среднее Task 1 : Task 2 = 1 : 2; Goethe — сумма с масштабированием до 100 |
| Терминология экзамена на его языке | `officialName` критериев: «Task Response», «Erfüllung der Aufgabenstellung» |
| Правила экзамена — данные | `rules` рубрики (≤ 20 слов → Band 1 и др.) проверяются на шкале каждого критерия |
| Версии не переписывают историю | Результат хранит экзамен, рубрику и версию пайплайна; проверка целостности сверяет версию рубрики |
| Офсеты не зависят от алфавита | Цитаты в кодовых точках: тест с эмодзи и кириллицей |
| Ориентировочный показ — конфигурация, не код | `approximate` у шкалы; без него число не показывается |

## 3. Что нужно, чтобы добавить экзамен (на примере Goethe B1 Schreiben)

1. Проверенная конфигурация в `catalog/` с источниками и тестом фактов (как IELTS, D1).
2. Руководство по оценке для его рубрики своими словами (D §3) и, при наличии, правила рубрики.
3. Свой бенчмарк качества (ТЗ §15, фаза 8) — без него экзамен не открывается.
4. Языковые части: подсчёт слов (`whitespace-v1` подходит для латиницы и кириллицы; для языков без пробелов — новое правило),
   определение языка ответа, темы Edu на этом языке.
5. Код пайплайна, таблицы, API и интерфейс не меняются.

## 4. Известные ограничения

- Правило подсчёта слов не годится для языков без пробелов (китайский, японский) — понадобится отдельное правило.
- Руководство по оценке и бенчмарк — работа на каждый экзамен; архитектура её не отменяет (ТЗ §25 фаза 8).
