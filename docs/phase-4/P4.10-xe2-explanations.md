## 2. XE-2.0 — инвентарь (сделано 2026-11-26, бесплатно)

Скрипты: [scripts/xe2/](../../scripts/xe2/) — копии XE-1 с новыми типами (скрипты и промпты XE-1 не меняются: к ним привязаны
манифесты по SHA). Данные — `tmp/xe2/` (не в Git). Production — только чтение.

| | |
|---|---|
| Заданий | **6750** в 58 темах (спецификации есть у всех) |
| По типам | исправление ошибок 2544, выбор в пропуске 1367, выбор ответа 1158, вписать 721, порядок слов 493, перефразирование 248, формы слова 219 |
| По уровням | A1 2165, A2 1843, B1 1760, B2 1090 (без 108 отклонённых и с 6 пропущенными) |
| Происхождение | AI 6230, Mnemonic 520 (учительский ru у 332) |
| Черновики WG | у 5648 из 6230 AI-заданий; 1708 не называют ключ (из них 1248 — исправление ошибок) |

Новые для конвейера типы:
- **исправление ошибок** — все `find_and_fix` с одной ошибкой: модель видит предложение, ошибочный фрагмент и исправление;
- **перефразирование** — исходное предложение, задача («active to passive», «direct to reported»…), ограничение, принимаемые ответы;
- **формы слова** — глаголы (past, past participle) и прилагательные (comparative, superlative).
