## Фазы 4–6 (кратко)

- **4. Персонализация:** проверка ответов в Edu (план владельца) → практика; V1–V3 из G (построитель списков, квота по праву Exams);
  рекомендации и план (F); модерация коллокаций (G §3.1a). Заявка EX в банке WG — параллельно.
- **5. Task 1 Academic (данные → график кодом), GT Task 1, полная симуляция** — каждый со своим бенчмарком.
- **6. Оплата:** разовые доступы и пакеты (C2 §3.2), Paddle-каталог `exams`, лендинги и SEO, открытие индексации, отчёт калибровки,
  срок хранения бэкапов `multi`.

## Главные риски для сроков

1. Обобщение биллинга WG (P2.2) — работающие деньги; делать маленькими шагами.
2. Пайплайн оценки может не пройти пороги — тогда Фаза 1 повторяется с другим подходом, а MVP выходит как «только разбор».
3. Онлайн-проверка ответов в Edu — внешняя зависимость Фазы 4.
