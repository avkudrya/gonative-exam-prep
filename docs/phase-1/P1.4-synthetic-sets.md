## 2. Как вставляются ошибки (S)

1. На чистой основе каждое правило ищет места. Спан ошибки — всё совпадение: изменённое слово и слово-контекст, которое
   делает его ошибкой (`a important`, `has became`). Тогда находка, процитированная с любой стороны, пересекается со спаном.
2. Число ошибок 6–10 определяет сид `s-<id основы>`. Семейства берутся по кругу, минимум 5 разных. Между ошибками
   не меньше 25 символов, чтобы одна находка не накрывала две.
3. Основа, где мест меньше, **отклоняется**: прореженный набор ошибок не допускается.
4. Тяжесть: орфография, предлоги, `a/an`, наречие → прилагательное — minor; остальное — moderate. Major не вставляем:
   правила не умеют надёжно ломать смысл. Порог полноты E §3 (moderate/major ≥ 0.70) считается по moderate.
5. Каждая ошибка хранит `rule`, `original`, `inserted`: в отчёте можно смотреть полноту по правилам.

Правила, которые иногда дают допустимый английский, сужены, и тест проверяет, что на верном тексте они молчат. Примеры:
- `in future` — верный британский вариант, не участвует;
- артикль после `and/or` не убирается;
- `reach a decision` не превращается в `make a decision`: это верное выражение;
- у собирательных `data`, `media` и подобных согласование не ломается;
- существительное вместо прилагательного (`society problems`) берётся только там, где оно точно неверно: `education policy` — нормальный английский.

**Что показали реальные основы.** Первая версия каталога (40 правил) на текстах уровня Band 8 находила места почти
только для орфографии и run-on; три основы не набирали 5 семейств. Каталог расширен до 61 правила за счёт типичных
ошибок, для которых в хорошем тексте всегда есть место: лишний или пропущенный артикль, модальный глагол с формой
прошедшего времени, `discuss about`, согласование с `this/these + существительное`, путаница `-ed/-ing`. Итог
по 40 эссе:

| Семейство | Ошибок |

| Орфография | 51 |

## 3. Ожидания G

| Случай | Откуда | Ожидание |
|---|---|---|
| 12 и 20 слов | вручную | `early: short_response` |
| 21 слово | вручную | правило не срабатывает; `underLength`; task ≤ 4 |
| Русский, немецкий | вручную | `early: wrong_language` (немецкий — латиница, проверка не только по алфавиту) |
| Один абзац | основа | `singleParagraph`; CC ≤ 5 (ограничитель абзацев) |
| Список | основа | `listForm`; TR ≤ 4 (не эссе) |
| Копия задания | основа | `copiedPrompt` (первое предложение задания дословно) |
| 150–200 слов | основа | `underLength`, без `early` (недобор сам по себе не штрафуется, P1.1 §4) |
| Чужое задание | основа + задание другой темы из той же части | TR ≤ 2, CC ≤ 3, LR ≤ 4, task ≤ 5 |
| Инструкция оценщику | основа со вставленными ошибками | ошибки по-прежнему ожидаются (метрики S); task и GRA ≤ 8 — «band 9» не выполнено |
| Слабое эссе с инструкцией | вручную | task ≤ 6, GRA ≤ 5 |
| Заученный шаблон | вручную | TR ≤ 6, LR ≤ 6 |
| Необычный, но верный стиль | вручную | task ≥ 6.5, LR и GRA ≥ 7: оценщик не наказывает стиль |

Итого G: 6 преобразований × 2 части + 10 вручную = **22** (11 dev / 11 test). S: **40** (20 / 20).
