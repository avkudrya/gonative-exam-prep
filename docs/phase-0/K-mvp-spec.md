# K. Спецификация MVP (Фазы 2–3)

**Статус:** v1, утверждён владельцем 2026-11-23. **ТЗ:** §7, §16, §26 K.
**Пометки 2026-11-24** (gate Фазы 3, [P3-gate](../phase-3/P3-gate.md) §6): строки «Оценка» и «Результат» приведены к
тому, что построено.
**Условие:** MVP строится после отчёта бенчмарка Фазы 1; если отчёт скажет «только разбор», из MVP убирается
ориентировочный диапазон, остальное не меняется.

## 1. Объём

| Область | В MVP |
|---|---|
| Экзамены | IELTS Academic и General Training — **Writing Task 2** (рубрика общая, пользователь выбирает экзамен) |
| Хосты | `exams.mnemonicwords.app` (приложение, `/{locale}/ielts/...`); `ielts.mnemonicwords.app` — лендинг с переходом на регистрацию |
| Языки интерфейса | en, ru, uk (uk добавлен в Фазе 3 по решению владельца 2026-11-25, до публичного запуска) |
| Язык объяснений | en / ru / uk, выбирается в профиле |
| Аккаунт | Общий аккаунт GoNative: регистрация, вход, Google, восстановление пароля, профиль Exams, согласие с условиями, 16+ |
| Задание | Библиотека из ~30 оригинальных заданий Task 2 (сгенерированы и проверены, с пометкой «неофициальные») + своё задание с проверкой |
| Редактор | Текст задания, счётчик слов («примерно»), необязательный таймер 40 мин, автосохранение черновика (сервер + локальная копия), защита от потери текста |
| Оценка | Пайплайн P1: правила кодом, 4 критерия, по одному вызову на критерий, без проверки находок вторым вендором (решения P1.7 и P1.9, P2-gate §6; было «пайплайн D … проверка находок»); статус оценки; повтор того же текста не тратит квоту |
| Результат | Сводка по критериям (сильные стороны / что мешает) + ориентировочный диапазон (ADR-003) с подписью; эссе с подсветкой находок (четыре вида: ошибка, слабое место, можно улучшить, сильная сторона — P3.9); «исправить в первую очередь» — до 5 навыков с числом мест и примерами (P3.9; было «3–5 главных исправлений»); объяснения на языке пользователя; «пожаловаться на оценку» |
| История | Список попыток, повторное открытие результата, удаление попытки (физическое) |
| Прогресс | Тренд по критериям (диапазоны) и «частые ошибки» по навыкам |
| Официальный результат | Форма «я сдал экзамен» с отдельным согласием на калибровку (ADR-003) |
| Лимиты | Бесплатно — гипотеза: 2 оценки в месяц; ручная выдача доступа владельцем (`product_entitlements`, источник `manual`) для тестирования |
| Приватность | Политика и условия Exams (en/ru), раздел об AI-оценке, удаление данных Exams и общего аккаунта |
| Админка | Прогоны оценки (шаги, модели, стоимость, ошибки), жалобы, версии экзаменов и руководства |

## 2. Не входит в MVP

Оплата (Фаза 6; до неё — бесплатный лимит и ручные доступы), рекомендации, практика, лексические списки и план (Фаза 4),
Task 1 и полная симуляция (Фаза 5), загрузка DOCX/PDF/фото, SEO-страницы кроме лендинга,
мобильное приложение, Reading/Listening/Speaking.

## 3. Критерии приёмки

1. Новый пользователь с лендинга `ielts.` регистрируется в `exams.`, выбирает IELTS Academic, пишет эссе, получает результат —
   на en и ru, на телефоне (320 px) и десктопе.
2. Закрытая вкладка или перезагрузка не теряют набранный текст.
3. Ответ ≤ 20 слов получает Band 1 без платного вызова AI; ответ на другом языке — Band 0; короткий ответ — предупреждение.
4. Каждая находка в результате подсвечивает реальный фрагмент текста; находок без цитаты, не совпавшей с текстом, нет.
5. Число показывается только как ориентировочный диапазон с подписью; нигде нет «официальной оценки» или «вашего балла IELTS».
6. Инструкция модели внутри эссе не меняет поведение оценки (тест).
7. Стоимость каждой оценки видна в админке; превышение лимита на оценку даёт `partial`, а не повторные платные вызовы.
8. Удаление попытки удаляет её текст; удаление данных Exams не трогает GoNative и Worksheets.
9. Страницы приложения закрыты от индексации; лендинг индексируется только после решения владельца.
10. Тесты бэкенда (Exam, обобщённые продуктовые модули, тесты WG без регрессий) и веба (сборка, типы, линт, e2e основного пути) зелёные.
