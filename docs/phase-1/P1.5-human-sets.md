# P1.5. Наборы с человеческими оценками: H1 (ELLIPSE) и H2 (EWCCE)

**Статус:** 2026-11-23. H1 собран (бесплатно). H2 заблокирован: в опубликованном архиве нет оценок.
**Основано на:** [E](../phase-0/E-benchmark-plan.md) §2–3, [E1](../phase-0/E1-reference-data.md) (лицензии).

## 1. H1 — ELLIPSE

| | |
|---|---|
| Источник | [ELLIPSE-Corpus](https://github.com/scrosseye/ELLIPSE-Corpus), Crossley et al. (2023), **CC BY 4.0** (README) |
| Что взято | dev — 50 эссе из `train.csv`, test — 100 из `test.csv` (zip с паролем из README) |
| Отбор | 200–500 слов (в среднем 349). Все 7 оценок есть. Выборка **по слоям общего балла** с сидом `h1-<split>`: шкала покрыта целиком, а не только её плотная середина (баллы 3–3.5) |
| Эталон | `traits`: overall, cohesion, syntax, vocabulary, phraseology, grammar, conventions — средние двух оценщиков |
| Задание | В ELLIPSE есть только метка темы («Distance learning»). Задание элемента — нейтральная формулировка «Write an essay giving and supporting your opinion on the following topic: …». H1 сравнивает только CC, LR и GRA (`traitMap` из P1.3 §3), TR в нём не участвует |
| Где тексты | `benchmarks/datasets/exam-h1-v1/raw/` (в git не попадает). Коммитится `source.json`: лицензия, авторство, SHA исходных файлов, отобранные id, SHA `items.jsonl` |
| Сборка | `npm run bench:h1 -- <папка с train.csv и test/…csv>` — та же выборка при тех же файлах |

Оговорки:
- ELLIPSE — школьники 8–12 классов США, изучающие английский. Это не IELTS: другие задания и своя шкала 1–5.
- Метрика — только ранговое согласие (Спирмен ≥ 0.5 по каждой паре, E §3), не совпадение полос.
- Много очень слабых текстов (уровень ниже Band 4). На них проверяется нижняя граница руководства (floor 3).

## 2. H2 — EWCCE: заблокирован

Архив скачан, SHA совпал с опубликованным на Mendeley. Внутри **только 200 сканов PDF**. Таблицы с оценками двух
преподавателей по критериям нет, хотя в описании набора она заявлена. Открыл два скана: это одна рукописная
страница на задание «paragraph, 100–150 words» на бытовые темы, а не эссе Task 2. Пометок оценщиков на скане нет.

Следствие: в Фазе 1 нет человеческого эталона в полосах IELTS. Порог E §3 для H2 (±1 полоса от среднего оценщиков)
проверить нечем. Расшифровку (≈ $2) не предлагаю: без оценок она бесполезна.

**Что это значит для решения Фазы 1 (ADR-003):**
- без эталона в полосах числа в интерфейсе остаются **ориентировочным широким диапазоном** (`presentEstimate`);
- сузить диапазон или назвать оценку калиброванной данные Фазы 1 не позволяют;
- решение «разбор + ориентировочные полосы» или «только разбор» опирается на S, G, R и H1.

Варианты закрыть пробел (решает владелец, не срочно):
1. Написать авторам EWCCE и попросить таблицу оценок. Даже тогда это абзацы, а не эссе.
2. Экзаменаторы, путь 1 из E1 «Путь к калибровке»: двойная оценка 100–200 эссе. Это деньги, нужна отдельная смета.
3. Официальные результаты пользователей после экзамена: с Фазы 6, нужно согласие.

Находки — в `benchmarks/datasets/exam-h2-v1/source.json`.
