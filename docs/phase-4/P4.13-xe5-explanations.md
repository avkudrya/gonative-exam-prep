## 2. Протокол

- **Один шаг, только Opus 5.5**: он пишет и проверяет объяснения en/ru/uk каждого задания. Opus принимал решения во всех
  прежних волнах. Черновик Haiku на 74 заданиях почти ничего не экономит.
- **Настройки XE-4:** Batches, adaptive thinking, effort medium, 20 заданий в запросе, `max_tokens` = 1500 + 600 на задание.
  Пилота нет.
- **Промпт:** [scripts/xe5/prompts/opus-review.md](../../scripts/xe5/prompts/opus-review.md). Это промпт XE-4 без пересмотра:
  на входе правила темы и задания. Действие `write` — Opus пишет тексты, `reject` — ответ задания неверен, задание уходит в WG.
  Для пунктуации текст называет знак и правило. Сомнения, которые не делают ответ неверным, Opus пишет в `problem`, и они
  тоже уходят в WG.
