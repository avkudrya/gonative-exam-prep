## 2. Что сделано

**MultiAdmin:**
- **`ProductGuides`.** У Academic и GT одна рубрика `ielts-writing-task-1`, поэтому запись GT названа
  `ielts-writing-task-1@ielts-general-training`, и для экзамена GT она важнее общей. Параметры: `p1/exam-gt1-1`, только задания
  библиотеки, свой флаг.
- **Руководство GT v1 и библиотека из 24 писем** закреплены в `exam.data`. Импорт письма:
  - тип задания — тон;
  - `prompt` хранит текст и `letter-spec/1`;
  - форма задания проверяется: тон, три пункта, начало письма.

  Строки Task 2 и Academic не меняются.
- **Оценка.** Попытка несёт задание письма (адресат, тон, пункты) к оценщику. Версия промпта берётся из той, с которой разбор был
  принят.
- **Находки кода о начале и прощании** (en/ru/uk):
  - если приветствие или прощание не подходит адресату, это ошибка Task Achievement прямо на этой строке (например, «Yours
    faithfully» после «Dear Ms. Carter»);
  - если приветствия или прощания нет, это слабое место без места в тексте;
  - находка добавляется, только если модель сама ничего не отметила на этом месте. «Ошибка», у которой исправление совпадает с
    цитатой, отбрасывается, как у Academic.

**Сайт:**
- **Выбор задания.** У General Training появляются «Task 1: письмо» и «Task 2: эссе», но только когда бэкенд оценивает Task 1.
- **Список писем:**
  - фильтр по тону (официальное, полуофициальное, неофициальное);
  - в карточке — ситуация, адресат, три пункта и начало письма;
  - своего задания нет.
- **Редактор:** задание с пунктами, «Ваше письмо», условия Task 1 (20 минут, 150 слов).
- **Разбор:**
  - «Ваше письмо»;
  - навыки названы для письма: «Цель письма», «Раскрытие пунктов», «Все пункты задания»;
  - «Показать задание» без графика.
- **Проверено:** скриншоты списка и редактора.

## 3. Production — по шагам, всё делает владелец (ADR-004)

1. **Деплой MultiAdmin** `ebd0ce16` или новее. Для писем ничего не меняется, пока выключен флаг. Academic Task 1 с этого момента
   оценивается на `exam-t1-4`.
2. **Деплой сайта** `63e11e1` или новее. Могу сделать сам — скажите «деплой».
3. **Бэкап** двух таблиц, в которые пишет импорт (на сервере, спросит пароль sudo):

   ```bash
   ( set -euo pipefail; umask 077; sudo -v
     GT1_BACKUP=$(mktemp -d /home/gonativealex/deploy-backups/exams-gt1-before.XXXXXXXX)
     sudo /usr/bin/mysqldump --defaults-file=/root/.mybu.cnf --host=127.0.0.1 --port=7337 --protocol=tcp \
       --single-transaction --quick --hex-blob --skip-add-drop-table --skip-lock-tables --no-tablespaces \
       multi ex_practice_tasks ex_assessment_guides > "$GT1_BACKUP/gt1-before.sql"
     test -s "$GT1_BACKUP/gt1-before.sql"
     grep -q '^-- Dump completed on ' "$GT1_BACKUP/gt1-before.sql"
     chmod 600 "$GT1_BACKUP/gt1-before.sql"
     sha256sum "$GT1_BACKUP/gt1-before.sql" )
   ```

4. **Импорт.** Сначала предпросмотр, потом `--apply`. Команды только добавляют строки.

   ```bash
   cd /var/www/goapi.mnemonicwords.app/current
   php artisan exam:import-guide          # ожидается: 1 insert (ielts-writing-task-1-general v1), остальное unchanged
   php artisan exam:import-guide --apply  # Inserted 1
   php artisan exam:import-tasks          # ожидается: 24 insert (gonative-t1g:*), 54 unchanged
   php artisan exam:import-tasks --apply  # Inserted 24
   ```

5. **Флаг:** `EXAM_GT_TASK1_ENABLED=true` в `shared/.env`, затем то же, что при включении `EXAM_TASK1_ENABLED` (сброс кэша
   конфигурации и перезапуск воркера: `sudo supervisorctl restart 'laravel-exam:*'`).
6. **Живая проверка:**
   - Writing → «Новое эссе» → IELTS General Training → «Task 1: письмо» → любое задание;
   - письмо от 150 слов → «Получить разбор»;
   - ожидается разбор по Task Achievement, Coherence and Cohesion, Lexical Resource и Grammatical Range and Accuracy;
   - если закончить неподходящей формулой (например, «Love,» в письме в компанию), появится находка о прощании.

   Одна оценка стоит около $0.07 из вашей квоты.

**Замечания и что с ними сделано:**

| Замечание | Решение |
|---|---|
| «I am waiting for your answer» — три карточки «Улучшение» с одной и той же заменой под тремя критериями | **Исправлено кодом** (MultiAdmin `9f1ac977`): одинаковые улучшения склеиваются, как ошибки, в одну карточку со всеми критериями. Заодно исправлено, что при склейке трёх карточек терялся первый критерий |
| «when the course will starts» — объяснение «после when о будущем не ставят will», хотя это косвенный вопрос, где will допустим | **В промпт**: косвенный вопрос — не придаточное времени; после модального глагола — голая форма |
| «or the college will provide it» → «or whether the college will provide it»: подстановка ломает прямой вопрос | **В промпт**: исправление должно быть верным, когда его подставили в предложение; не смешивать прямой вопрос с whether. Проверить грамматику кодом нельзя |
| «how many lessons are in one week» отмечено ошибкой, а это верный вопрос к подлежащему | **В промпт**: вопросы к подлежащему; there не обязателен |
| «I am working during the day» отмечено ошибкой, хотя это допустимо о текущем графике | **В промпт**: допустимую форму времени не называть ошибкой без опоры на контекст |
| «Sometimes I am watching videos» — по отзыву, это подсказка, а не ошибка | **Не согласен**: речь об общей привычке, и для этого уровня это типичная ошибка. Её тяжесть minor, это верно |
| «Повтор I» в слабых местах | **В промпт письма**: «I» в личном письме естественно |
| Countability названо словообразованием, артикль «on internet» — сочетаемостью; группы «Строение предложений» и «Времена» смешивают разные правила | Точнее навыки нужны для упражнений «Потренироваться». Это задача таксономии навыков, в бэклог Фазы 6 |
| В группе «5 мест» видно 3 примера | Так задумано: до трёх разных примеров, все места есть в списке ниже. Ссылка «все места» — в бэклог сайта |
| Сильная сторона с названием «Все пункты задания» на одной фразе | Мелочь в выборе навыка моделью, в бэклог |

**Пункты промпта** касаются грамматики во всех заданиях: Task 2, Academic и письме. Их проверка требует замера, поэтому их лучше
собрать в одну следующую версию: `exam-p1-7`, `exam-t1-5` и `exam-gt1-2`. В эту версию войдут тесты 06–07 и регрессионные
примеры GT-01…GT-20 из отзыва, переписанные своими словами. Раунд с замером предложу отдельно, после P5.12.
