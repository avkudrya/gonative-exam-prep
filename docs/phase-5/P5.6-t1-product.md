## 2. Что сделано

**MultiAdmin:**
- **`ProductGuides`.** Один помощник решает, каким руководством, конвейером и промптом оценивается задание для данного экзамена.
  Для Task 1:
  - только IELTS Academic: у General Training в Task 1 письмо, это P5.7 и дальше;
  - только задания библиотеки: у своего задания нет данных графика;
  - `p1/exam-t1-3`;
  - выключено, пока нет `EXAM_TASK1_ENABLED=true`.

  Task 2 не изменился.
- **Библиотека Task 1** (24 задания) импортируется вместе с данными (`stimulus`) и тем, что читает оценщик (`visual`: таблицы и
  факты кода).
  - Два задания с «revise» в проверке тоже попадают в продукт: библиотека записывает, что правки внесены.
  - Хэши строк Task 2 прежние.
- **Оценка:** задание с графиком оценивается со своими данными и тем промптом, с которым было принято. Если флаг выключат уже после
  отправки, оценка всё равно дойдёт.
- **Результат:**
  - число, которого нет в данных, становится ошибкой Task Achievement на en/ru/uk: «Это число не совпадает с данными графика…»;
    такая находка добавляется, только если модель сама ничего не отметила на этом месте;
  - «ошибка», у которой исправление совпадает с цитатой, отбрасывается: на test такие были 2 из 15 (§5 P5.5). Фильтр работает
    только для Task 1.

**Сайт:**
- **Выбор задания.** «Task 1: график» и «Task 2: эссе» — только у Academic и только когда бэкенд оценивает Task 1.
  - Список Task 1 — задания с картинкой графика и фильтром по типу (линия, столбцы, круговая, таблица, два графика).
  - Своего задания нет.
- **Редактор:**
  - график рисует код; кнопка «Показать данные таблицей»; пометка «Данные придуманы для практики»;
  - условия Task 1: 20 минут и не меньше 150 слов в подсказке, таймере и окне отправки.
- **Разбор:** под заголовком — «Показать задание и график», чтобы сверять находки с данными. Критерий Task Achievement добавлен в
  порядок и названия.
- **Совместимость:** запросы Task 2 те же, `task_key` уходит только для Task 1. Старый бэкенд сайт тоже переживёт: Task 1
  просто не появится.
- **Проверено:** скриншоты списка и редактора в светлой и тёмной теме.

**Пока не сделано (не мешает запуску):**
- тренды на странице прогресса и в «моих результатах» показывают критерии Task 2; Task Achievement в них не попадает;
- темы заданий показываются ключом в нижнем регистре («transport»), как и у Task 2.

## 3. Production — по шагам, всё делает владелец (ADR-004)

1. **Деплой MultiAdmin** `fc8b1a41` или новее. Флаг выключен, поэтому для пользователей ничего не меняется.
2. **Деплой сайта** `cbe200f` или новее. Без флага Task 1 не виден.
3. **Бэкап** двух таблиц, в которые пишет импорт (на сервере, спросит пароль sudo):

   ```bash
   ( set -euo pipefail; umask 077; sudo -v
     T1_BACKUP=$(mktemp -d /home/gonativealex/deploy-backups/exams-t1-before.XXXXXXXX)
     sudo /usr/bin/mysqldump --defaults-file=/root/.mybu.cnf --host=127.0.0.1 --port=7337 --protocol=tcp \
       --single-transaction --quick --hex-blob --skip-add-drop-table --skip-lock-tables --no-tablespaces \
       multi ex_practice_tasks ex_assessment_guides > "$T1_BACKUP/t1-before.sql"
     test -s "$T1_BACKUP/t1-before.sql"
     grep -q '^-- Dump completed on ' "$T1_BACKUP/t1-before.sql"
     chmod 600 "$T1_BACKUP/t1-before.sql"
     sha256sum "$T1_BACKUP/t1-before.sql" )
   ```

4. **Импорт.** Сначала предпросмотр, потом `--apply`. Команды только добавляют строки.

   ```bash
   cd /var/www/goapi.mnemonicwords.app/current
   php artisan exam:import-guide          # ожидается: 1 insert (ielts-writing-task-1-academic v1), остальное unchanged
   php artisan exam:import-guide --apply  # Inserted 1
   php artisan exam:import-tasks          # ожидается: 24 insert (gonative-t1a:*), 30 unchanged
   php artisan exam:import-tasks --apply  # Inserted 24
   ```

5. **Флаг:** `EXAM_TASK1_ENABLED=true` в `shared/.env`, затем то же, что при включении `EXAM_REWRITE_CHECK_ENABLED` (сброс кэша
   конфигурации).
6. **Живая проверка:**
   - Writing → «Новое эссе» → IELTS Academic → «Task 1: график» → любое задание;
   - отчёт от 150 слов → «Получить разбор»;
   - ожидается: разбор по Task Achievement, Coherence and Cohesion, Lexical Resource и Grammatical Range and Accuracy;
   - если в отчёте неверное число — находка «Это число не совпадает с данными графика».

   Одна оценка стоит около $0.07 из вашей квоты.

**Замечания и что с ними сделано:**

| Замечание | Решение |
|---|---|
| В списке у заданий-таблиц нет картинки, только подпись | Исправлено: превью показывает саму таблицу (`63e5348`) |
| В разборе Task 1 — «Ваше эссе», «Развитие идей», «Ясная позиция» | Исправлено: «Ваш отчёт»; навыки — «Обзор», «Ключевые особенности и сравнения», «Точность и полнота данных»; en/ru/uk (`63e5348`) |
