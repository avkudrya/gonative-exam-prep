# Бенчмарки оценки

Манифесты датасетов, конфигурации прогонов и отчёты Фазы 1 (план — `docs/phase-0/E-benchmark-plan.md`,
набросок в [docs/plan/phase-0-audit.md](../docs/plan/phase-0-audit.md)). Прогоны выполняет MultiAdmin
(`Exam\Bench` поверх `Edu\Ai`), результаты кладутся сюда.

## Планируемая структура

```
benchmarks/
  datasets/
    <dataset-id>/
      manifest.json   источник, лицензия, что разрешено, split (dev/test), хэши файлов
      raw/            тексты третьих лиц — НЕ коммитятся (.gitignore)
      items.jsonl     только наши синтетические тексты или то, что лицензия разрешает хранить
  sources/            наши задания Task 2, ручные случаи G, основы S (синтетика, коммитится)
  s-bases/            платный скрипт основ S: пишет один вендор, вычитывает другой (P1.4)
  tools/              сборка наборов S и G: вставка ошибок, преобразования, npm run bench:build
  guide-review/
    run.php           один платный вызов: смысловая проверка руководства по оценке вторым вендором (P1.1)
    <guide>.<version>/
      system.txt, schema.json, manifest.json   промпт, схема ответа, модель, оценка стоимости, лимит
      response.json, receipt.json              ответ и фактическая стоимость (после запуска)
  runs/
    <run-id>/
      config.json     модели, промпт-версии, пайплайн, лимит в $
      metrics.json    итоговые метрики
      REPORT.md       выводы
      responses/      сырые ответы моделей — НЕ коммитятся
```

## Правила

1. **Лицензия до данных.** У каждого внешнего источника в `manifest.json` есть ссылка, лицензия
   и разрешённые действия. Нет подтверждения — текст не попадает в репозиторий.
2. **Никаких эссе пользователей.** Только публичные эталоны с разрешённым использованием и наши
   синтетические тексты.
3. **dev отдельно от test.** Промпты и калибровку настраиваем только на dev.
4. **AI-оценки — не эталон.** Ответ модели и сгенерированный «образцовый» текст никогда не
   записываются как оценка экзаменатора (ТЗ §9.1).
5. **Деньги.** Каждый платный прогон — с лимитом, который заранее утвердил владелец; фактическая
   стоимость попадает в отчёт и в PLAN.md.
