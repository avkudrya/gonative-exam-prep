# P5.13. Раунд 5 — точность объяснений и исправлений

Владелец, 2026-11-27: «да, раунд 5 до $13». Цель: меньше ложных ошибок на допустимых вариантах и ни одного исправления,
которое ломает предложение, без потери полноты. Основание — замечания тестов 06–09 владельца ([P5-plan](P5-plan.md), журнал).

Потрачено **$12.0161 из $13**.

## 1. Что сделано

- **Промпты** (MultiAdmin `8b7b7a11`): `exam-p1-7` для Task 2, `exam-t1-5` для Academic Task 1, `exam-gt1-2` для письма GT.
  Новые правила включает предикат `AssessmentPrompts::p17()`. Старые версии не изменились: сверены все 336 вариантов промптов.
  - Сначала решить, что слова делают в предложении, потом применять правило. Придаточное времени и косвенный вопрос — разные
    случаи; вопрос к подлежащему не требует инверсии.
  - Конструкция, которую принимает стандартный английский, — не ошибка, даже если другая встречается чаще. Если модель не
    уверена, что это ошибка, — улучшение с явной пользой или ничего.
  - Исправление проверяется в предложении целиком. Если правка выходит за цитату, цитата расширяется.
  - Улучшение не меняет смысл и регистр; связки ради связок не добавляются.
  - «Повторяющаяся ошибка» — только одна и та же ошибка больше одного раза. Повтор слова сначала пересчитывается в тексте.
  - Task 2: ответ оценивается относительно точного утверждения в задании.
  - Личное письмо: «I», сокращения, фразовые глаголы и разговорные обороты естественны.
- **Набор `exam-precision-v1`** (`npm run bench:precision`, источник `benchmarks/sources/precision-v1.json`): 12 коротких
  ответов, которые я написал сам, по 4 на каждое задание. В них 59 проб:
  - 29 допустимых вариантов, из них 7 названы в промпте прямо;
  - 30 настоящих ошибок с принятыми исправлениями.

  Задания взяты из библиотеки: Task 2 — p24, p13, p06, p28; Academic — t1a-01, t1a-11, t1a-13, t1a-19; GT — gt1-14, gt1-05,
  gt1-21, gt1-23. Письма проходят проверку письма кодом без замечаний, цифры Academic сверены с данными графика.
- **Метрика проб** (`EssayBenchMetrics::probes`, MultiAdmin `8b7b7a11`), отчёт — раздел «Probes»:
  - ложные ошибки на допустимых вариантах;
  - полнота на ошибках;
  - исправление, подставленное в предложение, совпало с одним из принятых предложений.

- **Task 2.** Новая версия больше не помечает ни один из вариантов, названных в промпте. Осталась одна ложная ошибка:
  «the council are» (собирательное существительное во множественном числе, британская норма); в промпте этот случай не назван.
- **GT.** Обе версии помечают «spend ages on looking» и обе пропускают ошибку «you are very busy since». Новая версия к тому

- **Исправления.** Ни в одной версии нет исправления, которое ломает предложение: все исправления найденных ошибок после
  подстановки дают принятое предложение. Тот класс ошибок из тестов владельца на коротких ответах не воспроизвёлся.

### Academic: ослаблен ограничитель «нет обзора» (`benchmarks/runs/exam-t1a-overview-1`, $0.9547)

В `exam-t1a-dev-5` не прошла проверка G `g-t1-no-overview-dev`: оценка TA 7 при ожидаемой не выше 5. Для проверки оба
ограничителя «TA не выше 5» (нет обзора; только перечень цифр) прогнали по 3 раза на обеих версиях:

| Пункт | `exam-t1-4` | `exam-t1-5` |
|---|---|---|
| `g-t1-no-overview-dev` | TA 5, 5, 5: ограничитель есть 3 из 3 | TA 7, 7, 7: ограничителя нет 3 из 3 |
| `g-t1-data-dump-dev` | TA 4, 4, 4 | TA 4, 4, 4 |

Это не случайность. Новая версия пишет: «отдельного обзора нет, но основная картина видна по абзацам; ограничитель не
включаю, хотя обзор слабый». Правило «не уверен, что это ошибка, — улучшение или ничего» модель перенесла с языковых замечаний
на ограничители. Отчёт, где цифры только перечислены, обе версии ограничивают одинаково.
